16 个功能模块，每个都写清楚解决什么问题、怎么用、注意什么。 左侧目录可跳转，滚动时会自动高亮当前章节。

📖这是什么

一个完全在浏览器本地运行的营销分析与内容工作台。它不联网、不上传、不需要账号—— 打开就能用，关掉数据还在你自己的浏览器里。

和常见营销 AI 工具最大的区别是：它不生成"一段话让你去别处执行"，而是尽量 直接算出结论。目前有 12 个确定性分析函数，同样输入永远得到同样输出。

一句话定位：营销人的本地分析工具箱 —— 能算的不交给模型，算不了的诚实告诉你。

六步

步骤算什么
0 待验证假设不计算 —— 追踪"已验证 / 待验证 / 已推翻"
1 市场测算TAM / SAM / SOM
2 竞品 × 画像交叉找"所有竞品都没满足"的空白格
3 用户分层占比校验（应为 100%）
4 定价验证支付意愿曲线（可选标准 Van Westendorp）
5 可行性与风险分期路线 + 风险清单
为什么假设放在第 0 步：一份开头就写"这几条是我的假设，第 3 条还没验证"的报告， 比填满一百个数字的更可信。生成的报告会自动警告还有几条未验证。

关于定价模型的纠正

常见错误：用单题问卷（"你愿意付多少"）的数据去套 Van Westendorp。 这个模型需要每个受访者回答四个独立问题（太便宜/便宜/贵/太贵）。

本工具默认改用支付意愿（WTP）曲线，标准模型做成可选项。另外做了 计费口径分离——月费档和一次性档不能混在同一条收入曲线上比，否则会算出荒谬的最优价。

☑ 最高档为「一次性付费」，不计入订阅收入对比

📡热点决策方法论层

用户流程
热点池选节点 / 粘贴突发热点→五道闸门→建议姿态 + 事前验尸→选动作（放弃 / 轻量 / 追踪 / 肯定跟）→记入台账→开内容包 / 送去体检→事后回填结果
它回答「该不该跟、怎么跟」，不做事实核查——红线命中会一票否决。

判断该不该跟热点，而不是"热点是真是假"。

为什么不做"求真"：验证真伪需要联网抓取权威数据源，纯前端做不到， 且说错了要负法律责任。而营销翻车 90% 不是因为热点是假的， 是热点是真的但不该跟（灾难、逝者、社会悲剧）。

入口：可预期热点池（40 个节点）

热点分两类，做法完全不同：

类型举例本工具做法
突发型塌房 / 事故 / 突然爆梗无法预测，只能手动粘贴评估
可预期型春节 / 618 / 开学季 / 颁奖季内置节点池，自动排到时间轴上
为什么不做"实时热点雷达"：突发热点需要抓取 API，会破坏「零依赖、本地运行」的底线。 更要命的是——等你发现、评估、出物料，窗口早就关了。 而可预期热点提前一年就确定，可以提前准备，这才是本工具（排期 / 工作流 / 内容包）真正能帮上忙的地方。

节点池按距今天数自动分四档，并给出"该准备了"的提前量：

状态判定含义
进行中距今 ≤ 3 天黄金期，内容应已在投放
该准备了距今 ≤ 提前量筹备与预热窗口
还早距今 > 提前量可先记入排期
已过已过去 3 天以上自动指向明年

每个节点带三样内容：通常怎么赢（典型打法）、容易翻车（该节点的高频坑）、情绪倾向。 点「载入评估 →」把节点带入下方表单。

五道闸门（不是加权打分）

为什么弃用五维加权打分：热点是负偏态决策——收益有上限（多一波声量）， 损失无下限（品牌翻车不可逆）。期望值算出来是正的，但尾部风险能吃掉十次成功。 加权打分会用虚假精确感掩盖尾部风险。闸门是"能不能碰"的定性判断，不是"值多少分"。 原五维打分降级为背景信息，不再输出总分。
闸门回答什么机制
① 红线筛查能不能碰🔴 禁止触碰一票否决；🟡 谨慎降档；🟢 正常流程
② 品牌契合跟我的价值观一致吗读品牌内核的品类禁忌，检测冲突
③ 时滞 vs 窗口还来不来得及纯算术：剩余窗口 − 响应时滞 − 起量时间
④ 参与姿态用多重的力度参与五档：沉默 / 轻量跟随 / 借势改写 / 重度绑定 / 反向输出
⑤ 事前验尸如果翻车，最可能因为什么7 项 checklist 逐项排除

闸门三：唯一能真算的一关

绝大多数热点不是"不该追"，是来不及。大家都在纠结要不要追，没人算最快多久能出物料。

有效窗口 ＝ 热点剩余窗口 － 响应时滞（文案＋设计＋审批，可选串行或并行）－ 发布后起量时间
结果为负即"参与不了"——不是"建议观望"，是这个热点你根本挤不进去。 这把"感觉来不及"变成了"确实来不及 6 小时"。

闸门四：追不追是个错误的二选一

热点参与不是布尔值，是个梯度。五档姿态各有成本、风险与适用条件：

姿态成本风险适用
沉默零零红线命中 / 价值冲突 / 明显来不及
轻量跟随极低低时间紧 / 预算小 / 不确定值不值
借势改写中中价值契合 + 有时间做内容
重度绑定高高强相关 + 窗口足 + 预算到位
反向输出中高很高仅 🟢 类 + 极强表达把控力
"不追"常常不是最优解，"轻量跟随"才是——用近乎零的成本拿存在感，不押品牌资产。 这跟本工具其他模块的气质一致：克制是特性。但克制不是"不做"，是"选最小的那档做"。

闸门五：事前验尸（Pre-mortem）

不问"我们会成功吗"，而是问：假设一周后翻车了，最可能的三个原因是什么？

人预测失败时的判断力显著强于预测成功。7 项逐一排除：热点反转 / 关联人出负面 / 冒犯某群体 / 竞品已占位 / 审批太慢 / 用力过猛 / 价值观冲突。

反向角度：只在 🟢 类开放

追热点最大的问题不是慢，是同质化——所有人说一样的话。真正的差异化是角度，不是速度。 工具提供三种角度对照：主流叙事（要避开的）、反向切入（解构质疑）、侧向迁移（把情绪迁移到自己产品）。

硬约束：反向角度只在 🟢 一般类热点提供。🟡🔴 类一律不提供—— 在敏感话题上"抖机灵"极易演变为冒犯。这个功能本身很妙，但没有约束就是定时炸弹。

决策动作

动作含义
放弃归档，不投入任何资源
轻量跟随最低成本拿曝光，不押品牌资产
继续追踪进观察池，设定复评条件后暂缓
肯定跟投入资源，走完整内容流程
动作不是终点，是台账的起点：点任意一个动作，本次决策（热点、结论、姿态、动作） 会记入热点台账，事后可回填实际结果。

热点台账：让「追得对不对」有答案

「追不追」是当下决策，但「追得对不对」只有事后才知道。没有回填，每次决策都从零开始， 无法形成「我们品牌适合追什么」的规律——那才是长期值钱的东西。

点「回填结果」记录实际效果（曝光 / 转化 / 有无负面）并写一句复盘。台账会显示 已回填 N 条，并作为第 8 类记录（🔥 热点追踪）出现在品牌轨迹里。

样本不足（< 5 条）不统计规律——沿用本产品一贯原则：宁可少说， 也不说一个自己都不信的数字。3 条记录推出的「我们擅长 X」是噪声冒充洞察。 满 5 条后才会显示各动作的实际分布。

非红线热点还可点「📦 开内容包生产」，把热点语境带入内容包，直接开始生产； 或点「📝 送去内容工厂」做合规体检。

天花板不可逾越

系统推荐姿态受多重天花板约束，且任何"提升"规则都不得突破它：

  • 红线命中 → 强制沉默，不参与后续任何评估
  • 🟡 谨慎类 → 最高只到「轻量跟随」
  • 检测到品类禁忌冲突 → 最高只到「轻量跟随」
  • 有效窗口 ≤ 0 → 强制沉默
  • 相关性或契合 ≤ 2 分 → 最高只到「轻量跟随」
  • 反向输出永不作为系统自动推荐——只作对照与可选提示

🏛️品牌内核方法论层

用户流程
填文化内核（MVV）→填价值层级（逐级抽象）→选品类 + 给维度打分→选收入模式与变现策略→诊断结论 + 价值曲线图
品牌是承诺，商业模式是履约结构，两者必须互相锁定。填不出使命愿景时，可先用「人格调性」反推。

品牌是承诺，商业模式是履约结构。这里自上而下定义三层，再检测它与你的赚钱方式是否自洽。

三层结构

层内容
1 文化内核使命 / 愿景 / 价值观
2 价值层级功能 → 情感 → 自我表达，必须逐级抽象
3 人格调性Tone of Voice（MBTI 是反向入口，不是起点）
+ 商业模式收入模式 + 变现策略，只做一致性检测，不算单位经济

五类诊断

诊断规则
主战场得分 ≥ 4.0 的维度数量（2-5 个健康）
记忆点与品类基准偏离 ≥ 0.5 的维度
撕裂价值主张关键词 vs 实际维度投入
抽象度相邻价值层词元重合度（≥ 0.3 判为复述）
变现冲突变现策略 × 维度，仅当该维度是真实重心时触发
为什么主战场用绝对分而不是比值：奢侈品品类的「身份象征」基准本来就 4.5 分， 若要求"高于基准 30%"，等于要 5.85 分——永远达不到，会把所有奢侈品误判成"没有主战场"。 所以主战场看绝对分（≥4.0），差异化另用「绝对偏离 ≥0.5」衡量。

位置型维度

价格定位没有好坏方向：高 = 溢价端，低 = 性价比端。星巴克在溢价端不是缺点，是选择。 所以「高频折扣」只在价格处于溢价端（≥3.8）时才算冲突——瑞幸做折扣不冲突，奢侈品做折扣才冲突。

基准线说明：10 个品类的基准是经验参考值，不来自任何数据库，可在界面上拖动调整。

采集阶段的跑偏判断

这是纯前端规则判断，不调用任何 LLM——没有网络请求、没有 token 消耗、不会幻觉， 适合结构化字段的采集。四类判断：

  • 空 / 纯表情 / 过短——先过滤掉没有实际内容的输入
  • 疑问句——命中问号或疑问词即判跑偏，但加了长度豁免
  • 分字段黑名单——每个问题有自己的词表，不共用
  • 长度上限——超过 40~80 字提示精简
为什么疑问句要加长度豁免
朴素正则会把「我们的目标人群是 25-35 岁都市白领？」判成提问——但它其实是有效回答， 只是句末带了个问号。所以规则改成：只有 15 字以内的疑问句才算真提问。 同理，黑名单按字段隔离，避免问「行业」时用户提到「竞品」就被误判。

容忍机制：连续 2 次跑偏才会提示「也可以直接跳过」，且每个可跳过的题都常驻「跳过」出口—— 判断错了要能立刻绕开，而不是把用户困住。

边界：规则只用于采集，不用于粘贴
这套判断只服务「问一个问题、等一个短答案」的场景（第 1 阶段）。 执行阶段那些「把 AI 产出粘回来」的步骤不适用——用户粘的是几百字正文， 用疑问句/黑名单判断它对不对没有意义。那里改用可复制提示词 + 字数提示解决「卡住」的问题。

  • 知识库 > 50 篇 或 > 2 MB → 提示清理
  • 有单篇 > 100 KB → 提示拆分

知识库软上限

知识库是唯一「无条数上限 + 高频粘贴长文」的地方，因此单独加了提醒：

  • 保存单篇超 5 万字（约 100 KB）→ 弹窗告知占用并建议拆分，但不阻止保存
  • 总量超 50 篇或 2 MB → 保存后提示一次（不重复打扰）
  • 文档列表底部常驻显示「共 N 篇 · X KB」，超限转橙

做法是「知情」而非「禁止」——用户有权存长资料，工具只负责让他知道代价。

❓常见问题

数据会丢吗？

清浏览器缓存、换浏览器、无痕模式都会丢。 请定期到「⚙️ 系统设置」导出全量备份（JSON）——一次导出即可保存全部 21 个模块的数据， 需要时用「恢复备份」整体还原。各模块的导出按钮适合单份内容交付， 全量备份适合防丢与迁移。两者用途不同，建议都要。

为什么生成的是提示词不是成品文案？

因为不联网、不接模型。这是定位取舍，不是未完成功能。创作类任务必须靠外部模型执行。

能多人用吗？

当前是单用户本地工具。要协作需自建后端，那会改变产品定位。

为什么不用 LangChain / ECharts？

LangChain 是接 LLM 的胶水层，本工具核心是确定性计算，引入它不带来新能力， 却会破坏"零依赖"卖点。ECharts 同理，且所有图表手写 SVG 都够用。

填了品牌记忆没效果？

检查左侧「品牌记忆」开关是否打开，以及知识库引用设置。点「👀 预览注入效果」可确认。

开始前为什么要先问几句

内容包是通用流程，但你的品牌、目标、限制是具体的。先问清楚，后续每一步的提示词才会带上这些信息——比如"基于 Y.Mine 手工香薰、目标是涨粉、不提折扣"生成的标题，和空白设定下生成的完全不同。

每题都可以跳过，答案不会阻塞流程。

输入校验的规则

情况处理
空输入 / 纯表情 / 少于 2 字提示补充
短疑问句（如"美妆？"）判定为在提问，拉回本题
长句带问号通过——确认语气的有效回答不该被拦
命中该字段的黑名单词拉回本题
要求填数字却没数字提示补数字
要求简短却超 60 字提示精简
为什么中间步骤不校验内容质量
执行阶段让你粘贴的是 AI 跑完的产出，几百字。规则判断无法衡量它好不好——硬判只会误伤正常的长文本。 所以中间步骤只检查有没有填，质量由你判断。这不是偷懒，是刻意的边界。
关于连续答偏
第 1 次答偏给出柔和提示（💡），第 2 次才加强语气（⚠️），并且任何时候都能点「跳过这题」。 不阻塞、不指责。
